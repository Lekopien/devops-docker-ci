Ship it like production

A service packaged with a hardened multi-stage Docker image, nginx load balancing three replicas, Redis, health probes, Prometheus metrics and a GitHub Actions pipeline that tests, lints, smoke-tests the stack and publishes to GHCR.

View sourceRun it locally

Highlights

Tests inside the build

The Dockerfile has a test stage; a failing test means no image.

Load balanced

nginx round-robins across replicas, re-resolving DNS so scaling just works.

Hardened

Non-root user, read-only filesystem, no-new-privileges, resource limits, security headers.

Observable

Liveness and readiness probes, Prometheus metrics, JSON logs from app and proxy.

Resilient

Rate limiting, upstream retries, graceful SIGTERM shutdown, Redis fallback.

Full pipeline

Unit tests, hadolint, compose integration and smoke test, publish to ghcr.io on main.

Run it

Run the stack

git clone https://github.com/Lekopien/devops-docker-ci
cd devops-docker-ci
make up      # nginx + 3 app replicas + redis
make smoke   # health, readiness, load balancing, rate limiting
make scale N=5

Architecture

 :8080 ──► nginx ──round-robin──► app ×3 ──► redis
           rate limit, gzip     /healthz /readyz /metrics

Pipeline

push/PR ─► test (unittest + hadolint)
        ─► integration (docker compose up --wait + smoke.sh)
        ─► publish (main only → ghcr.io/lekopien/devops-docker-ci)
